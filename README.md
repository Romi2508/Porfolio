The portfolio is designed with a clean dark-themed developer interface and focuses on responsive design, component-based development, and a smooth user experience.

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Romi2508/Porfolio.git
```

### 2. Navigate to the project

```bash
cd Porfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

---

## 🏗️ Build for Production

Create a production build using:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
